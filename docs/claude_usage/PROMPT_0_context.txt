## Goal
From scholarly articles (mostly PDFs) reporting psychological questionnaire /
interview scores, extract descriptive statistics (mean, median, SD, min, max,
individual values) into a fixed long-format schema (one CSV per publication),
which I later concatenate and aggregate. We are at the extraction step.

## The normalized long-format schema (16 columns, fixed)
Built by scaffold.make_row(). Columns:
  publication          - short citation, e.g. "Hagborg et al. 2022"
  scale_old            - the label AS WRITTEN in the paper (stay close to source)
  data_type            - mean | median | sd | minimum | maximum | individual
  sample_type          - patients | healthy_controls  (community counts as
                         healthy_controls)
  subsample            - diagnosis / demographic group, or "whole_sample"
  sample_size          - group n, or "NA"
  value                - the number
  source_file          - filled automatically at consolidation (leave default)
  scale                - MY normalized scale name (I decide it — ask me)
  subscale             - MY normalized subscale name, or "none" (ask me)
  item_name            - the item's text/label (item rows only), else "none"
  record_type          - total | subscale | item
  redcap_item_number   - items only; else "none". I fill the numbers later.
  scoring_rule         - "unverified" by default; if the paper states the rule
                         explicitly, do NOT set it silently — see rule below
  item_score_reversed  - items only: "yes" | "no"; else "none"
  redundant_aggregate  - True if a whole-sample value overlaps its own subsamples

## What YOU populate vs. what I decide
- Populate directly: publication, scale_old, data_type, sample_type, subsample,
  sample_size, value, record_type.
- ASK ME to define `scale` and `subscale` (the normalized names) — do not invent

- scoring_rule: default "unverified". If the paper states the scoring rule

- redcap_item_number: always "none" (I fill later).
- item_name: for item rows, use the item's text/wording (a bare number is often

- redundant_aggregate: if a whole-sample value overlaps its own subsamples,

- Present the SAMPLE INFORMATION from the paper: the exact quote(s) describing

- Then ASK me to set two flags for the publication:
    sample_with_mental_illness : 1 if the patient sample consists of people with

Community samples: treat as healthy_controls (I no longer use a separate

## Folder convention

## Code architecture
- scaffold.py is STABLE (schema, make_row, split_paren, validate_rows,

- Each paper gets a SWAPPABLE module named after its PDF, exposing

- Readable, modular code (small functions, no monster function), pitched for a
  biologist who knows some Python and needs to debug it.
- Per-paper module filenames replace hyphens with underscores (DES-T_…pdf →
